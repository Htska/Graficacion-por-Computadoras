# Contents
* [Bezier](https://github.com/Htska/Graficacion-por-Computadoras/tree/main/Bezier) :  Small SFML animation using Bezier curves.
* [CamaraOrbital](https://github.com/Htska/Graficacion-por-Computadoras/tree/main/CamaraOrbital) : OpenGL project, implementing an Orbital Camera.
* [clase2](https://github.com/Htska/Graficacion-por-Computadoras/tree/main/clase2) : Small C++ code to show syntax.
* [clase3](https://github.com/Htska/Graficacion-por-Computadoras/tree/main/clase3) : 2D Vector class.
* [clase5](https://github.com/Htska/Graficacion-por-Computadoras/tree/main/clase5) : SFML project to create Bezier curves.
* [clase6](https://github.com/Htska/Graficacion-por-Computadoras/tree/main/clase6) : 3D Vector template class
* [claseSfml](https://github.com/Htska/Graficacion-por-Computadoras/tree/main/claseSfml) : SFML code for drawing and moving two squares.
* [JuegoDeLaVida](https://github.com/Htska/Graficacion-por-Computadoras/tree/main/JuegoDeLaVida) : Homework based on my Game of Life [project](https://github.com/Htska/GameOfLife).
* [MandelbrotZoom](https://github.com/Htska/Graficacion-por-Computadoras/tree/main/MandelbrotZoom) : OpenGL app that displays the Mandelbrot set with the ability to perform a zoom.
* [openGL1](https://github.com/Htska/Graficacion-por-Computadoras/tree/main/openGL1) : First OpenGL code, draws a simple triangle.
* [openGL2](https://github.com/Htska/Graficacion-por-Computadoras/tree/main/openGL2) : OpenGL code for drawing Sierpinski triangle.
* [openGL3](https://github.com/Htska/Graficacion-por-Computadoras/tree/main/openGL3) : OpenGL code for drawing multiple figures inside another using the Fragment shader.
* [openGL3D](https://github.com/Htska/Graficacion-por-Computadoras/tree/main/openGL3D) : A first 3D cube in openGL.
* [openGl4](https://github.com/Htska/Graficacion-por-Computadoras/tree/main/openGl4) : OpenGL code for drawing a heart in the fragment shader.
* [openGL5](https://github.com/Htska/Graficacion-por-Computadoras/tree/main/openGL5) : OpenGL code for drawing the Mandelbrot set in the fragment shader.
* [Rotaciones](https://github.com/Htska/Graficacion-por-Computadoras/tree/main/Rotaciones) : OpenGL code for showing multiple transformations.
